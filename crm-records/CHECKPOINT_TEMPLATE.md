# 商机点检模板

对商机各维度进行结构化质量检查，判断每个维度是否与客户达成一致，识别信息缺口和风险点。

## 输入

```
【商机标识】
商机号：{如 ZP2600448204}
客户：{姓名 + 职位}
点检人：{点检执行人}
点检日期：{YYYY-MM-DD}

【同事沟通记录】
（粘贴与客户/地面部队的最新沟通记录，包括拜访记录、邮件、消息等）
```

## 点检维度与推进动作对照

根据点检结果选择下一步动作：

| 点检发现 | 建议动作 |
|----------|----------|
| 报价未达成一致 | 委托拜访，了解客户对报价最担心的一点 |
| 付款条件未确认 | 委托拜访，带回客户融资/付款的具体要求 |
| 产品配置未明确 | 委托拜访，帮客户做选型确认（带方案去，不是带问题去） |
| 资信信息缺失 | 协调内部，确认信审进度和缺什么材料 |
| 交期未对齐 | 内部确认供应链状态后再跟客户沟通 |
| 服务条款有差异 | 委托拜访，确认客户核心关切（不要逐条谈判） |
| 多个维度未达成 | 按优先级逐个击破，先解决客户最关心的那个 |

## 使用说明

1. 将同事沟通记录粘贴到输入区
2. 提供商机号和客户名
3. AI 根据沟通记录填写点检报告各维度
4. 点检结论决定后续流程：合格→继续拜访/跟进，不合格→优先补正
5. 将点检报告追加到对应商机记录文件的「沟通记录」章节下
6. 点检维度对照表可帮助确定下一步委托消息的具体动作
