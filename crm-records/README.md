# CRM Records — 商机委托拜访记录

## 背景

- **角色**：商机负责人（人在中国）
- **场景**：收到拉美当地同事（地面部队）的沟通记录，需分析现状并委托下一步拜访任务
- **市场**：洪都拉斯等拉美地区，客户为西语使用者
- **产品**：中联重科工程机械设备（矿用自卸车、破碎设备、挖掘机等）

## 工作模式

```
同事沟通记录（三段式：点检 → 拜访 → 跟进）
        │
        ▼
  商机现状分析（客户/进展/未完成/难点）
        │
        ▼
  委托消息生成（中文 + 西班牙语）
        │
        ▼
  发给当地地面部队执行
```

## 使用方式

1. 在 `records/` 目录下为每个商机创建 `.md` 文件，以商机编号命名（如 `ZP2600449617.md`）
2. 每次收到同事新的沟通记录，追加到对应文件中
3. 向 AI 提供模板和记录，生成分析 + 委托消息
4. 委托消息可直接发给当地执行人

## 委托原则

| 原则 | 说明 |
|------|------|
| **单任务聚焦** | 每次只委托一个核心动作，不让地面部队困惑 |
| **可执行明确** | 说清楚"做什么、问什么、带回什么" |
| **礼貌用语** | 中文加"你好/麻烦/非常感谢"；西语加"Hola amigo/Muchísimas gracias" |
| **标注禁区** | 明确禁止提及的内容（如付款条件、价格比较等） |
| **带回信息** | 要求地面部队带回具体的客户反馈，而非模糊判断 |
