# 委托拜访消息生成模板

## 输入

```
【字段模板】
商机标识：{从记录里找}
客户：{从记录里找}
已确认信息：{从记录里找}
本次推进事项：{根据记录决定具体动作}
禁止提及：{明确不能谈的内容}
语气：柔和

【同事沟通记录】
（粘贴三段式记录：点检 → 拜访 → 跟进，按时间先后排列）
```

## 输出

### 第一步：商机现状分析

```
【商机现状分析】

客户：{姓名}，{职位}。{公司背景/实力}

当前进展：{已达成共识、客户表态、我方已完成的动作}

未完成事项：{客户尚未确认/完成的关键动作}

客户状态/难点：{竞争关系、客户顾虑、决策瓶颈}
```

### 第二步：委托消息（中文 + 西班牙语）

```
【委托消息 - 中文】
你好，麻烦请拜访{客户姓名+职位}，{单一核心动作}。{禁止提及内容}，保持协助姿态。非常感谢！

【委托消息 - 西班牙语】
Hola amigo, por favor visita a {nombre y cargo del cliente} y {acción única y concreta}. Sin mencionar {prohibiciones}, mantén una actitud de apoyo. ¡Muchísimas gracias!
```

## 委托消息写作要点

| 要素 | 要求 | 示例 |
|------|------|------|
| 单任务 | 一次只要求一件事 | "只问一个问题：他最担心的点是什么" |
| 可执行 | 说清楚做什么、带什么回来 | "带回客户对融资的具体要求（额度、期限、担保等）" |
| 禁止项 | 标注禁区 | "暂时不提付款" / "不提价格比较" |
| 问候 | 中文+西语礼貌用语 | "你好/麻烦" / "Hola amigo" |
| 感谢 | 结尾致谢 | "非常感谢！" / "Muchísimas gracias" |
| 长度 | 不超过5行 | 短小精悍，直接可转发 |

## 常见推进事项参考

根据沟通记录中出现的具体情况选择：

- 客户在分析报价 → "了解他最担心的一个点是什么（性能/售后/价格）"
- 客户要看车 → "确认具体日期和随行人数"
- 客户在谈融资 → "带回客户对融资的具体要求"
- 客户有替代方案 → "确认对替代方案的具体顾虑"
- 需要跨团队协调 → "带回双方可匹配的日期/条件"
