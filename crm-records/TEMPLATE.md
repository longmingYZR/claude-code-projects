# 委托拜访消息生成模板

## 前置步骤：商机点检

在生成委托消息之前，先用 `CHECKPOINT_TEMPLATE.md` 对商机做一次结构化点检：

1. 将同事沟通记录粘贴到点检模板的输入区
2. AI 填写点检报告的 9 个维度（报价/付款/产品/资信/交期/服务/其他/核心难点/下一步计划）
3. 根据点检结论决定下一步：
   - **各维度基本一致** → 继续下面的委托消息生成流程
   - **存在信息缺口** → 优先委托补正信息缺失的维度
   - **信息严重不足** → 暂停推进，先做信息收集

## 输入

```
【字段模板】
商机标识：{从记录里找}
客户：{从记录里找}
已确认信息：{从记录里找，参考点检报告中「已达成」的维度}
本次推进事项：{根据点检报告中的信息缺口决定具体动作}
禁止提及：{明确不能谈的内容}
语气：柔和

【同事沟通记录】
（粘贴三段式记录：点检 → 拜访 → 跟进，按时间先后排列）
```

## 输出

### 第一步：商机现状分析

```
【商机现状分析】

客户：{姓名}，{职位}。{公司背景/实力}

当前进展：{已达成共识、客户表态、我方已完成的动作}

未完成事项：{客户尚未确认/完成的关键动作}

客户状态/难点：{竞争关系、客户顾虑、决策瓶颈}
```

### 第二步：委托消息（中文 + 西班牙语）

```
【委托消息 - 中文】
你好，麻烦请拜访{客户姓名+职位}，{单一核心动作}。{禁止提及内容}，保持协助姿态。非常感谢！

【委托消息 - 西班牙语】
Hola amigo, por favor visita a {nombre y cargo del cliente} y {acción única y concreta}. Sin mencionar {prohibiciones}, mantén una actitud de apoyo. ¡Muchísimas gracias!
```

## 委托消息写作要点

| 要素 | 要求 | 示例 |
|------|------|------|
| 单任务 | 一次只要求一件事 | "只问一个问题：他最担心的点是什么" |
| 可执行 | 说清楚做什么、带什么回来 | "带回客户对融资的具体要求（额度、期限、担保等）" |
| 禁止项 | 标注禁区 | "暂时不提付款" / "不提价格比较" |
| 问候 | 中文+西语礼貌用语 | "你好/麻烦" / "Hola amigo" |
| 感谢 | 结尾致谢 | "非常感谢！" / "Muchísimas gracias" |
| 长度 | 不超过5行 | 短小精悍，直接可转发 |

## 常见推进事项参考

根据点检报告和沟通记录中出现的具体情况选择：

### 信息补正类（点检未达成时优先）
- 报价未达成一致 → "了解客户对报价最担心的一点是什么（性能/售后/价格）"
- 付款条件未确认 → "带回客户对融资/付款的具体要求（额度、期限、担保等）"
- 产品配置未明确 → "帮客户确认选型方案，带回他对配置的具体需求"
- 资信信息缺失 → "内部确认信审进度和缺什么材料"
- 交期未对齐 → "确认客户最晚可接受的交期，内部同步供应链状态"
- 服务条款有差异 → "确认客户对服务条款的核心关切（不要逐条谈判）"

### 推进类（点检基本一致时）
- 客户在分析报价 → "了解他最担心的一个点是什么（性能/售后/价格）"
- 客户要看车 → "确认具体日期和随行人数"
- 客户在谈融资 → "带回客户对融资的具体要求"
- 客户有替代方案 → "确认对替代方案的具体顾虑"
- 需要跨团队协调 → "带回双方可匹配的日期/条件"
