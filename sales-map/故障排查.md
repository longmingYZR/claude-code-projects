# 高德地图批量打点工具 — 故障排查笔记

本文记录本次排障中遇到的典型问题与处理方式，便于日后对照。

## 项目说明

- **文件**：`index.html`、`style.css`
- **能力**：Leaflet + OpenStreetMap 底图；SheetJS 读取 `.csv` / `.xlsx` / `.xls`；高德 REST **地理编码**接口 `/v3/geocode/geo` 将地址转为经纬度并打点。

---

## 问题 1：API Key 未生效

**现象**：地理编码失败，或请求行为异常。

**常见原因**

- 源码中 `GAODE_KEY` 仍为占位符 `YOUR_GAODE_KEY_HERE`。
- 使用了错误类型的 Key（需使用高德开放平台的 **Web 服务** Key，勿与 JS API Key 混用）。
- 控制台中为 Key 配置了域名 / IP / 安全策略，当前访问来源不在允许范围内。

**处理**

- 在页面「高德 Web服务 Key」输入框粘贴并 **保存到本机**（`localStorage`），或直接在 `index.html` 中替换 `GAODE_KEY`。
- 在高德控制台核对 Key 类型、配额及 **HTTP Referer / 域名白名单** 等设置。

---

## 问题 2：表头为 `Column1`、`Column2`…

**现象**：表格有数据，但程序识别不到地址列，打点数为 0。

**原因**：部分 Excel 导出只有默认列名 `Column1`、`Column2`…，与脚本中约定的「地址 / address / Addr」等列名不一致。

**处理**：当按列名无法匹配到地址时，通过启发式规则 **自动推断最可能为地址的一列**（例如综合文本长度、中文、省市区路等特征），再用该列参与地理编码。

---

## 问题 3：CSV 表头带 BOM（`\uFEFF`）

**现象**：肉眼能看到「地址」列，程序仍读不到。

**原因**：UTF-8 BOM 会使首列表头实际键名为 `\uFEFF地址`，而不是 `地址`。

**处理**：解析表格后，对每个表头键名 **去除 BOM 并 trim**。

---

## 问题 4：中文 Windows 下的 GBK CSV

**现象**：`.csv` 列名乱码，无法匹配地址列。

**原因**：Excel「逗号分隔 CSV」在中文环境下常为 **ANSI/GBK**，若按 UTF-8 解析会得到乱码。

**处理**：对 `.csv` 文件，若默认解析下列名匹配失败，可尝试使用 **`codepage: 936`** 再次读取；若解析出的有效地址行更多，则采用第二次结果。

---

## 问题 5：高德返回 `CUQPS_HAS_EXCEEDED_THE_LIMIT`（`infocode: 10021`）

**现象**：HTTP 200，但返回失败信息；部分行打点失败，`successCount` 明显小于总行数。

**原因**：请求 **频率（QPS）或并发** 超过当前 Key 的限制（例如批量间隔过短，约 100ms 一次相当于约 10 QPS，容易触发限制）。

**处理**

- 适当 **增大两次地理编码请求之间的间隔**（例如约 400ms，需结合配额调整）。
- 若返回 `10021`，进行 **退避重试**（等待后同一地址再次请求）。

---

## 问题 6：`ENGINE_RESPONSE_DATA_ERROR`（如 `infocode: 30001`）与极短「地址」

**现象**：控制台或日志中出现对字面量「地址」的查询失败；样本长度仅 2 个字符。

**原因**：数据里混入了 **表头文字「地址」** 作为一行内容，不应调用地理编码。

**处理**：对明显无效的字符串（过短，或等于「地址 / 详细地址 / address」等表头占位词）**跳过请求**，避免浪费配额。

---

## 问题 7：`file://` 打开页面时请求失败

**现象**：浏览器中报 CORS 或与跨域相关的 fetch 错误。

**原因**：本地 `file://` 协议下，部分浏览器对跨域 `fetch` 限制更严格。

**处理**：使用 **`http://localhost`**（或本机其他 HTTP 服务）打开同一目录下的页面；必要时地理编码在 fetch 失败时用 **JSONP** 等方式作为补充（依当前实现而定）。

---

## 问题 8：Leaflet 地图灰块或尺寸异常

**现象**：容器有高度，但地图未正确铺满或瓦片显示异常。

**处理**：在页面 **`window.load`**（或布局稳定后）调用 **`map.invalidateSize()`**，让 Leaflet 按实际容器尺寸重新计算。

---

## 快速自检清单

1. Key 是否为 **Web 服务** Key、是否已保存 / 写入；配额是否充足。
2. 表头是真实业务列名还是 **`ColumnN`**；是否需要自动推断地址列。
3. CSV：**BOM**、**UTF-8 与 GBK** 编码是否匹配。
4. 批量请求是否 **限速**；日志或网络面板是否出现 **`10021`**。
5. 数据中是否混入 **「地址」等表头行**。
6. 是否尽量使用 **HTTP 访问**（如 `localhost`），避免长期依赖 `file://`。
